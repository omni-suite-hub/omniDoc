# OmniDoc

macOS 万能文档预览器 —— 一个应用打开六种文档格式，全部在本地完成，不上传、不联网、不依赖外部服务。

支持 **PDF · Word (.docx) · Excel (.xlsx/.xls/.csv) · PowerPoint (.pptx) · Markdown · 纯文本/代码**

## 特性

- **完全离线** —— 解析和渲染全部在本机进行，没有任何数据外传
- **零依赖安装** —— 单个 dmg，拖入「应用程序」即用
- **实时统计** —— 在 Excel 里框选任意区域即时显示计数、求和、平均值、极值
- **键盘友好** —— `⌘C` 复制（自动转 TSV，Excel/Numbers/Sheets 可直接粘贴）、方向键导航、`Esc` 清除选择
- **中文字体完备** —— 内置 pdf.js CMap 与标准字体，繁体与生僻字不缺字

## 使用

| 操作 | 说明 |
| --- | --- |
| 打开文件 | 拖入窗口、点击欢迎页卡片，或 `⌘O` 呼出系统对话框 |
| 打开文件夹 | 欢迎页「打开文件夹」，支持整目录浏览 |
| 表格框选 | 在单元格里按住拖动；点行号/列标选整行整列；`⌘` 加选多块 |
| 表格统计 | 框选后底部实时显示计数 / 求和 / 平均 / 极值 |
| PDF 翻页 | 内容不足一屏时滚轮翻页；能滚动时先滚动，到边界才翻页 |
| PPT 翻页 | 滚轮或 `←` `→` |
| 搜索 | `⌘F` |

表格里选中区域后按 `⌘C`，内容以 TSV 形式进入剪贴板 —— 直接粘到 Excel 表格软件里就是规整的多行多列。

## 设为默认打开方式

应用内「关于」弹窗 → 可把 OmniDoc 设为 PDF、Word、Excel、PPT、Markdown、纯文本的默认打开应用。

也可以在「系统设置 → 通用 → 默认应用」里手动指定。

## 安装要求

- macOS 10.15 或更高版本
- Apple Silicon（arm64）

> 本项目使用 ad-hoc 签名，未做苹果公证。首次打开若提示「无法验证开发者」，
> 请在「系统设置 → 隐私与安全性」中点击「仍要打开」。

## 更新

应用内「关于」→「检查更新」会查询本仓库的 GitHub Releases，有新版本时会提示并提供下载地址。

## 技术栈

| 层 | 选型 |
| --- | --- |
| 桌面壳 | Tauri 2 |
| 前端 | Vue 3（Composition API）+ Vite 8 |
| PDF | pdf.js（Web Worker 独立 chunk） |
| Office 解析 | SheetJS / JSZip + 自研 OOXML 解析器 |
| Rust 原生 | `serde_json` + `chardetng`（文本编码嗅探） |

前端资源编译进二进制，不依赖运行时服务器。

## 隐私

无账号体系、无埋点、无中转服务器。所有解析在本机完成。
